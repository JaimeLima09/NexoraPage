# NEXORA — Sitio Web Corporativo Interactivo

Plataforma web corporativa oficial de **NEXORA** — Socio Tecnológico para Empresas.

> **"Tecnología que impulsa tu negocio."**
> 
> *No tienes que saber qué tecnología necesitas. Solo tienes que saber qué problema quieres resolver.*

---

## 🚀 Características del Proyecto

- **Identidad Visual Oficial**: Construida a partir del logotipo oficial de NEXORA (`logo.png`), con paleta cromática limpia en tonos blanco, azul corporativo (`#2563eb`), azul marino (`#0b192c`), acentos turquesa/cian (`#00bfa5`) y fondos claros.
- **6 Demos Interactivas en Vivo**:
  1. *Sistema Empresarial (Mini ERP / Ventas)*: Registro de ventas dinámicas, adición de clientes, filtros y cambio de estado de pedidos.
  2. *Automatización de Procesos*: Comparativa interactiva Manual vs. NEXORA con simulador de ejecución paso a paso.
  3. *Inteligencia Artificial Aplicada*: Asistente corporativo interactivo con consultas predefinidas de negocio y efecto de mecanografía.
  4. *Dashboard Ejecutivo*: Tablero con selector de temporalidad (Semana / Mes / Año) y gráficos dinámicos.
  5. *Simulador de App Móvil*: Smartphone mockup con catálogo, carrito interactivo y confirmación de pedidos.
  6. *Integración de Sistemas*: Diagrama interactivo de nodos interconectados con simulación de flujo de datos en tiempo real.
- **Diagnóstico Digital Interactivo**: Cuestionario de 5 preguntas con cálculo en tiempo real de madurez digital y desglose en 4 pilares operativos.
- **Problemas Reales**: Casos y situaciones cotidianas explicadas en lenguaje de negocio accesible para cualquier tomador de decisiones.
- **9 Servicios Principales**: Explicación clara de impacto comercial, beneficios y entregables.
- **Metodología de 5 Pasos**: Proceso transparente y colaborativo.
- **Casos de Uso por Industria**: Ejemplos en Restaurante, Distribuidora, Servicios, Comercio e Industria.
- **Formulario de Contacto**: Validación en tiempo real, selección de servicio y confirmación interactiva.
- **100% Responsivo & Accesible**: Optimizado para dispositivos móviles, tablets, laptops y pantallas de escritorio.

## 🛠️ Tecnologías Utilizadas

- **React 18** + **TypeScript**
- **Vite 6** (Empaquetado ultrarrápido)
- **Tailwind CSS 3** (Diseño responsivo y personalización cromática de marca)
- **Lucide React** (Iconografía moderna y consistente)
- **Canvas Confetti** (Efectos interactivos en hitos de usuario)

## 💻 Instrucciones para Ejecutar Localmente

1. **Instalar dependencias**:
   ```bash
   npm install
   ```

2. **Iniciar servidor de desarrollo**:
   ```bash
   npm run dev
   ```
   Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

3. **Generar versión de producción**:
   ```bash
   npm run build
   ```

4. **Previsualizar versión de producción**:
   ```bash
   npm run preview
   ```
